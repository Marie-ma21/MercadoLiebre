# MercadoLiebre
Mercado Liebre es una aplicación web de comercio electronico, desarrollada como proyecto de práctica en desarrollo web. El objetivo es recrear la experiencia de navegación y visualización de productos de una tienda en línea, implementando vistas dinámicas con EJS y un servidor con Express.

## Características
- Servidor dinámico configurado con Node.js y Express
- Motor de plantillas EJS para header, footer y tarjetas de productos reutilizables
- Productos organizados por categorías: Hogar, Belleza y Calzado
- Modal interactivo con detalle de cada producto al hacer clic
- Vista de formulario de registro y login 
- Diseño responsive para móvil, tablet y escritorio

## Tecnologías
- Node.js
- Express
- EJS
- HTML5 / CSS3
- JavaScript

## Instalación
1. Clona el repositorio:
`[git clone https://github.com/Marie-ma21/mercado-liebre.git](https://github.com/Marie-ma21/MercadoLiebre.git)`

2. Instala dependencias:
`npm install`

3. Inicia el servidor:
`node app.js`

4. Abre en el navegador:
` http://localhost:3000 `
